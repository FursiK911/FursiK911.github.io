# Adaptive project modal height

## 2026-09-05 01:07 +03:00

- Type: fix
- Tags: ui, projects, modal, responsive, overflow, testing
- Summary: Replaced the project dialog's fixed desktop height with content-driven sizing, restored the complete project description, and added a compact short-viewport layout that keeps every field and action visible without scrollbars at the desktop breakpoint.
- Affected areas: `src/features/project-details/ui/ProjectDetails/styles/ProjectDetails.module.css`.
- Rationale: Long localized titles and descriptions could exceed the former 540px frame, clipping the role and details action even though the viewport had room for a taller dialog.
- Verification: Prettier, ESLint, TypeScript, and the production build passed. Browser measurements confirmed equal client and scroll dimensions at 1366×768 and 768×600 for the longest project preview; the details action remained fully inside the dialog. At 360×640 the intended vertical mobile scroll remained and horizontal overflow was absent. The full coverage run completed 106 of 107 tests and timed out one existing HomePage interaction test under parallel load; that test passed when rerun alone.
