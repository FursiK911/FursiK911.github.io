## 2026-09-04 20:06 +03:00

- Type: performance fix
- Tags: ui, hud, animation, performance, accessibility, testing
- Summary: Replaced discrete segment-width transitions with a continuously interpolated wave driven by one requestAnimationFrame loop.
- Affected areas: `src/widgets/site-layout/ui/HudScrollIndicator`.
- Rationale: The previous integer segment state made widths jump and triggered overlapping CSS transitions. The new loop uses a 60ms exponential follow, cached document geometry, transform-only width rendering, and direct DOM style writes without React updates for each frame.
- Verification: `npm run validate` passed: 100 test files and 100 tests, 89.66% statement coverage, 80.98% branch coverage, and a successful production build with the existing chunk-size warning. Graphify incremental refresh completed with 881 nodes, 1282 edges, and 118 communities.

## Decision DEC-20260904-02

- Drive the HUD wave from the fractional document position with transform scale and one cancellable rAF loop; keep accessibility state and localized text in React.
