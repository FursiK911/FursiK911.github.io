# Обновление резюме

Четыре PDF: Unity Developer и Frontend Developer, каждый на русском и английском. Текст находится в `content/*.json`. Изменяйте обе языковые версии согласованно. Поле `pages` задаёт границу между страницами; в frontend-версии запись ООО ЦУП продолжается на второй странице.

## Сборка

Из корня репозитория, с Python 3.11+:

```powershell
python -m pip install -r tools/resume/requirements.txt
python tools/resume/build.py
python tools/resume/verify.py
```

Генератор создаёт копии в `output/pdf/` и четыре канонических публикуемых файла в `public/cv/`: Unity Developer и Frontend Developer на русском и английском языках. Шрифты Ubuntu Regular/Bold включены с Ubuntu Font Licence; генерация не требует сети или исходных карьерных репозиториев. При неизменных версиях инструментов и текстах PDF побайтово воспроизводимы.

Для визуальной проверки используйте Poppler:

```powershell
pdftoppm -png -r 140 public/cv/Dmitry-Fursov-Unity-Developer-RU.pdf tmp/pdfs/unity-ru
```

Повторите для четырёх PDF и просмотрите все восемь страниц. Генератор прекращает публикацию комплекта при нарушении лимита страниц или размера. Проверка текста не заменяет визуальную проверку и не является сертификацией ATS.

## Сайт

`ResumeDownload` открывает выбор Unity / Frontend из Header, Hero, Contact и Footer. Язык файла соответствует языку сайта; неподдерживаемый язык получает EN. Другого переключателя языка в окне нет. Файлы доступны для проверки через локальный Vite preview.

По уточнению владельца от 14 сентября 2026 года сайт сейчас не опубликован: GitHub Pages workflow не запускать. Публикацию владелец выполнит самостоятельно после проверки резюме.

## Как адаптировать под вакансию

1. Выберите Unity для игровых/XR-позиций, Frontend для React/Next.js и frontend-oriented Fullstack.
2. Сопоставьте обязательные требования с подтверждёнными задачами; поднимите подходящие навыки и достижения выше внутри разделов.
3. При необходимости измените заголовок и краткий профиль. Не добавляйте технологии, стаж и результаты ради совпадения ключевых слов.
4. Сохраните корректную хронологию, уровень английского B1 и различие между коммерческими и учебными проектами.
5. Соберите PDF, проверьте текст и страницы. На сайте оставляйте базовые версии; персональные варианты для конкретных откликов храните отдельно.

Обоснование отбора и ограничения фактов: [исследование](research-2026-09-14.md).
