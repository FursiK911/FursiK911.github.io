## Agent workflow

Before adding project copy, metrics, media, links, or technical claims:

1. Open the matching research file from the source directory above.
2. Separate externally verified product facts from the portfolio owner's personal contribution.
3. Keep app installs, campaign/media views, book print runs, and retail footprint as separate metrics.
4. Do not turn an external product feature into a personal contribution without confirmation.
5. Keep user-facing copy in both `ru` and `en` i18next resources.

automatically scanned by a Graphify run rooted at the repository. If the

run Graphify separately on
`C:\Work\Резюме\app_from_portfolio_information\` or on a deliberate merged
corpus; do not copy research files into `src`.
